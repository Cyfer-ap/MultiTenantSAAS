ACCOUNT TYPES
-------------
Tenant users:
- Stored in APP_USERS
- Belong to exactly one tenant
- Roles:
  - TENANT_ADMIN
  - TENANT_MANAGER
  - TENANT_USER
- Receive accessToken and refreshToken

System admins:
- Stored in SYSTEM_ADMINS
- Do not belong to a tenant
- Role/account type:
  - SYSTEM_ADMIN
- Receive an accessToken
- System-admin refresh tokens are not implemented

DATABASE SAFETY
---------------
Do not delete the data/ directory as a normal migration fix.

For a persistent local database:
1. Stop the application.
2. Back up the data/ directory before manual recovery.
3. Preserve applied migrations.
4. Add a new migration for schema changes.
5. Use Flyway history to diagnose checksum or ordering issues.

Deleting data/ is only acceptable for an intentionally disposable local database after accepting complete data loss.
